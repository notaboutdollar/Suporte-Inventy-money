# NIDO Support CRM — Invent Money

Sistema interno de suporte pra triagem de tickets da comunidade de trainers da Invent Money.

## Stack
- Next.js 16 (App Router, TypeScript, Turbopack)
- React 19
- Tailwind v4
- Supabase (Postgres + Auth + Storage) — a instalar
- Vercel

## Dev

```bash
npm run dev
```

Abre em [http://localhost:3000](http://localhost:3000).
